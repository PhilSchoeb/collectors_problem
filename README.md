# Specified Collector's Problem
Implementation for a solution to a specified collector's problem - Stochastic Models (IFT3655)

In this specific problem, we buy boxes of 12 randomized items one at a time. There are 32 different items. Let's use C to denote the number of boxes that we need to buy to have a complete set of items (at least one of every kind). 

In this code, we calculate the probabilities P\[C = c\] for c = 1, ... , 50 and P\[C > 50\]. We do so using two different methods that I have called "pmr" and "vk" in my program.
